# 🍦 Nuvem Gelato — Site de Sorveteria

Site de uma sorveteria artesanal fictícia, desenvolvido em equipe como atividade da FIAP. O projeto tem duas páginas, **Home** e **Produtos**, construídas com componentes reutilizáveis.

## Tecnologias

- [React](https://react.dev/) — biblioteca de interface
- [Vite](https://vitejs.dev/) — ambiente de desenvolvimento e build
- [Tailwind CSS](https://tailwindcss.com/) — estilização
- [React Router DOM](https://reactrouter.com/) — navegação entre páginas

## Rotas

| Rota        | Página    |
|-------------|-----------|
| `/`         | Home      |
| `/produtos` | Produtos  |

## Como rodar o projeto

**Pré-requisito:** [Node.js](https://nodejs.org/) instalado.

```bash
# 1. Clone o repositório
git clone https://github.com/dos-1ESPI/cp-sorveteria.git

# 2. Entre na pasta
cd cp-sorveteria

# 3. Instale as dependências
npm install

# 4. Rode em modo de desenvolvimento
npm run dev
```

Depois, abra no navegador o endereço que aparecer no terminal (normalmente `http://localhost:5173`).
